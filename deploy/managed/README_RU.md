# AmneziaVPN: управляемый режим

Сборка AmneziaVPN, в которой обычный пользователь может только подключаться и отключаться.
Добавлять и менять подключения, открывать настройки может только администратор. Ключ пользователь не видит.

## Как получить установщик (один раз)

Собрать программу на своём компьютере сложно, поэтому собирает GitHub, бесплатно.

1. Зарегистрируйтесь на github.com (если ещё нет аккаунта).
2. Откройте https://github.com/amnezia-vpn/amnezia-client и нажмите **Fork** → **Create fork**.
   У вас появится своя копия программы.
3. В своей копии откройте вкладку **Actions** и нажмите «I understand my workflows, go ahead and enable them».
4. Наложите патч из архива на эту копию и отправьте её на GitHub (команды ниже, или попросите программиста —
   это 5 минут). Сборка запустится сама и может занять около часа.
5. Когда напротив сборки появится зелёная галочка, откройте её и внизу в разделе **Artifacts** скачайте файл
   `AmneziaVPN_..._windows_x64.exe`. Это и есть установщик.

Команды для шага 4 (нужен установленный Git):

```
git clone https://github.com/ВАШ_ЛОГИН/amnezia-client.git
cd amnezia-client
git checkout <коммит из BASE_COMMIT.txt>
git checkout -b managed-mode
git am путь\к\0001-feat-windows-managed-mode-with-admin-only-configurat.patch
git push origin managed-mode
```

## Установка на компьютер сотрудника

1. Под администратором установите `AmneziaVPN_..._windows_x64.exe`.
2. В PowerShell от администратора: `.\Set-AmneziaManagedMode.ps1 -Enable`
3. Правой кнопкой по ярлыку AmneziaVPN → «Запуск от имени администратора», добавьте ключ `vless://` или `vpn://`.
4. Закройте программу. Сотрудник при обычном запуске увидит только кнопку подключения.

На другие компьютеры можно не вводить ключ руками:

```
.\Set-AmneziaManagedMode.ps1 -Export C:\Secure\amnezia.reg            # на настроенном компьютере
.\Set-AmneziaManagedMode.ps1 -Enable -Import \\server\vpn$\amnezia.reg # на остальных
```

Вторую команду можно поставить в сценарий автозагрузки компьютера через групповую политику. Тогда, чтобы сменить ключ
на всех компьютерах, достаточно заменить файл на сервере. Доступ к папке дайте только группе «Компьютеры домена»:
в файле есть ключи.

## Нужно ли обновлять

Нет, установленная версия работает сама. Автопроверка обновлений в управляемом режиме отключена, а поставить
официальную версию поверх сотрудник не может: для установки нужны права администратора.

Обновлять стоит, только если:
- подключение перестало работать после изменений на сервере или блокировок (нужна новая версия Xray);
- Amnezia выпустила исправление безопасности.

Тогда заново синхронизируйте свою копию на GitHub (кнопка **Sync fork**), наложите патч, дождитесь сборки и
установите новую версию поверх. Настройки и ключи сохранятся.

## Что защищено

- **Интерфейс:** без прав администратора доступен только главный экран. Меню, настройки, импорт ключей,
  раздельное туннелирование и выбор протокола скрыты.
- **Ключ:** хранится в `HKLM\SOFTWARE\AmneziaVPN\Managed`. Читать его могут только SYSTEM и администраторы.
  Программа сотрудника получает копию, где ключи заменены подставными значениями. Настоящие подставляет служба
  в момент подключения.
- **Служба** проверяет каждое подключение и берёт настройки сервера из списка администратора, а не из запроса.
  Поэтому сотрудник не может подключиться к своему серверу и не может «выманить» ключ, перенаправив соединение.
  OpenVPN, Cloak и certutil через службу в этом режиме запрещены.

## Ограничения

- Поддерживаются VLESS, VMess, Trojan, Shadowsocks (через Xray), WireGuard и AmneziaWG. OpenVPN — нет.
- Не добавляйте сервер через «Настроить свой сервер» по SSH: используйте ключи `vless://` или `vpn://`.
- Дополнительные настройки Xray, сделанные в программе (padding, xmux и т.п.), могут не применяться:
  служба использует сохранённую конфигурацию подключения.
- Запустить другую VPN-программу сотрудник по-прежнему может. Это закрывается запретом запуска программ
  (App Control / AppLocker).

## Изменённые файлы

- `common/managed/managedPolicy.{h,cpp}` — режим, проверка прав, защищённое хранение, подстановка и проверка ключей.
- `ipc/ipcserver.cpp`, `ipc/ipcserverprocess.cpp`, `client/daemon/daemonlocalserverconnection.cpp`,
  `service/server/main.cpp`, `service/server/systemservice.cpp` — служба.
- `client/core/repositories/secureServersRepository.cpp` — список подключений из реестра.
- `client/core/controllers/selfhosted/importController.cpp`, `coreController.cpp`, `errorCodes.h`,
  `errorStrings.cpp` — запрет импорта и автообновления.
- `client/ui/qml/Pages2/PageStart.qml`, `PageHome.qml`, `client/amneziaApplication.cpp` — интерфейс.
- `client/translations/amneziavpn_ru_RU.ts` — русские строки.
